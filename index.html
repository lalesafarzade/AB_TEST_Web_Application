How to Use This Dashboard
  • Upload a CSV file with id column,group (A/B) and converted (true/false).
  • Click Analyze to run the A/B test.
  • Check P-Value and Z-Statistic.
  • If p-value < 0.05 → result is statistically significant.
  • Review the table and charts for insights.
